## 💻 Module 1: History of Computing

### The Invention of the World Wide Web (1989–1991)

One of the most important developments in computing history is the invention of the World Wide Web by **Sir Tim Berners-Lee** in 1989, which became publicly available in 1991. Before the Web, computers could share data, but there was no easy, unified way for people to navigate and access information across different systems.

Berners-Lee introduced the concept of hypertext — the ability to link documents together — combined with the Internet's existing infrastructure. This gave birth to web pages, web browsers, and URLs. Today, the World Wide Web is the foundation of how we communicate, do business, learn, and share information. Without it, modern applications, social media, e-commerce, and even this very portfolio would not exist. This development directly shaped how I use technology every day as a student and how I will use it as a future IT professional.

## My Computing Journey

### 🌐 What I Found Most Interesting in IT111: The Internet & How It Works

Among all the topics we covered in IT111 - Introduction to Computing, the one that I found most interesting and eye-opening was learning about **how the Internet works** — specifically, how data travels from one computer to another across a global network.

Before this class, I simply thought of the Internet as something you "connect to" without ever wondering how it actually functions. Learning about **IP addresses**, **protocols like HTTP and TCP/IP**, **servers**, and **browsers** changed the way I look at technology. It made me realize that every time I open a website, there is an entire invisible system working to retrieve, send, and display information for me — within milliseconds.

I found this topic useful because understanding the foundation of how the Internet works is essential for anyone pursuing a career in IT. Whether I become a web developer, a cybersecurity specialist, or a network engineer, knowing how data moves across networks will always be relevant and valuable.

#### Key Concepts I Learned:

1. **Internet:** A global system of interconnected networks that allows computers to communicate worldwide.
2. **IP Address:** A unique numerical label assigned to each device on a network to identify it.
3. **Protocol:** A set of rules that govern how data is transmitted between devices (e.g., HTTP, TCP/IP).
4. **Server:** A computer that stores and serves web content to users who request it.
5. **Browser:** A software application used to access and view web pages on the World Wide Web.

## ⚙️ Module 2: Computer Systems

### Creating This Portfolio — Input, Processing, Storage & Output

One activity I can connect to the computer systems model is the creation of this very portfolio website. Here is how the **Input → Processing → Storage → Output** model applies:

#### ⌨️ Input

I type HTML and CSS code using my keyboard in Visual Studio Code. The text, images, and links I add are all forms of input that I provide to the computer.

#### 🔄 Processing

The CPU processes my instructions. When I save and open the file in a browser, the browser's rendering engine interprets the HTML and CSS code and calculates how each element should be displayed.

#### 💾 Storage

My HTML, CSS, and image files are saved on the computer's hard drive (secondary storage). While working, the files and browser data are temporarily held in RAM (primary storage).

#### 🖥️ Output

The final output is the website displayed on the screen — a formatted, styled, and organized portfolio page that visitors can read and navigate.

## 🌍 Module 3: Connected World

### What Happens When Someone Visits My Portfolio?

When someone visits my portfolio website, a series of steps happen across the **Internet** to deliver my web pages to their screen:

1. The visitor opens a **browser** (such as Google Chrome or Firefox) and types in or clicks on the link to my portfolio.
2. The browser sends a request across the **Internet** — a massive global **network** of interconnected computers — to locate my website.
3. The request reaches a **server** — a computer that stores my website's files. The server is identified using an **IP address**, which acts as its unique location on the network.
4. The communication between the browser and the server follows a set of rules called a **protocol** — specifically **HTTP (HyperText Transfer Protocol)** — which defines how requests and responses are formatted and sent.
5. The server sends back my HTML, CSS, and image files to the visitor's browser over the **Web**.
6. The browser reads and renders the files, and the visitor sees my finished portfolio on their screen.

## 🔐 Cybersecurity: Protecting My Online Identity

As an IT student and an active internet user, it is important for me to practice good cybersecurity habits to protect my personal information and online identity. Here are the practices I follow:

#### 🔑 Use Strong, Unique Passwords

I use passwords that are long and contain a combination of uppercase and lowercase letters, numbers, and special characters. I avoid using easily guessable information like my name or birthdate. I also use different passwords for different accounts so that if one is compromised, the others remain safe.

#### 🛡️ Enable Multi-Factor Authentication (MFA)

Whenever a platform offers it, I enable multi-factor authentication. This adds an extra layer of security — even if someone gets hold of my password, they cannot access my account without the second verification step, such as a code sent to my phone.

#### ⚠️ Avoid Suspicious Links and Phishing

I am cautious about clicking on links in emails, messages, or websites that I do not recognize. Phishing attacks often disguise themselves as legitimate messages to trick users into giving away personal information. I verify the source before clicking anything suspicious.

#### 🔄 Keep Software and Devices Updated

I make sure to keep my operating system, browser, and apps updated regularly. Updates often include security patches that fix known vulnerabilities, making it harder for attackers to exploit my device.

#### 📶 Use Secure and Trusted Networks

I avoid accessing sensitive accounts or information when connected to public Wi-Fi networks, which may be unsecured. When using public networks is necessary, I take extra precautions and avoid logging into important accounts.

#### 🕵️ Protect Personal Information Online

I am mindful of what personal information I share online. I avoid posting sensitive details such as my full address, phone number, or financial information on public platforms or websites I do not fully trust.
